Hokusai renders text with libvips and Pango. `Hokusai.text(_:layout:style:)` returns an **ordinary immutable pipeline** (a transparent image of the text) that you can transform, composite or encode on its own; `drawText` is sugar for compositing that pipeline onto an existing one. Text rendering needs a libvips built with Pango (`Hokusai.capabilities().textRendering`), and a build without it reports `HokusaiError.unsupported` from the terminal, not from the call.

## Layout \{#layout}
`TextLayout` sets the size of the text box:

- `.natural` (default): as large as the text needs; lines break only at newlines.
- `.width(_:wrap:)`: wrap lines to a pixel width at the style's font size and DPI. `wrap` is `.word` (default), `.character`, `.wordCharacter` (word breaks, plus breaks inside a word too long for a line) or `.none`.
- `.fit(width:height:)`: the largest resolution at which the text fits the box. The style's `dpi` is not used and `lineHeight` must stay `1`.

## Typography: TextStyle \{#style}
| Property | Type | Default | Bounds |
| --- | --- | --- | --- |
| `font` | `String` | `"sans"` | Pango family and style without size, e.g. `"Helvetica Bold"`; **not** a file path. |
| `fontFile` | `URL?` | `nil` | A local TTF or OTF file made available to `font` for this render. Needs libvips with fontconfig; a file libvips cannot load is only a warning and the named `font` is used. |
| `fontSize` | `Int` | `24` | `1…2000` points at `dpi`. |
| `color` | `Color` | black | |
| `alignment` | `TextAlignment` | `.left` | `.left`, `.center`, `.right`. |
| `justify` | `Bool` | `false` | Stretches wrapped lines to the full width. |
| `lineHeight` | `Double` | `1` | `0.5…5`, multiple of the font's natural line height. |
| `dpi` | `Int` | `72` | `1…2400`; ignored by `.fit`. |
| `stroke` | `TextStroke?` | `nil` | Outline: `color`, `width` in `(0, 64]`. |
| `shadow` | `TextShadow?` | `nil` | `offsetX`/`offsetY` within ±10,000, `blur` `0…64` (default `1.2`), `color` (its opacity is the shadow's). |
| `rotation` | `Double` | `0` | Clockwise degrees; finite. |

Fonts come from the host: install what your application needs and use the installed family name. Package fonts with the app and load them with `fontFile` when the host cannot be controlled.

## Markup \{#markup}
`TextContent` is `.plain(String)` or `.markup(String)`; a string literal is plain. Plain text is always escaped, so any user string is safe to render. `.markup` is [Pango markup](https://docs.gtk.org/Pango/pango_markup.html) (not HTML or CSS) for mixed fonts, sizes and colours; invalid markup fails when the text is rendered.

## Drawing on an image \{#draw-text}
`drawText(_:placement:layout:style:)` composites the rendered text with the same placement, clipping and blending rules as any other layer ([Composition](/oss/hokusai/text-composition/composite)). `placement` is `.at(x:y:)` or `.gravity(_:offsetX:offsetY:)`.

## Errors \{#errors}
<Example id="text.limits" />

| Call | Result |
| --- | --- |
| `Hokusai.text("Hello", style: TextStyle(fontSize: 24))` | a 52 × 19 image |
| empty text | `invalidOption(name: "text", …"must not be empty")` |
| `font` that is a path (`/fonts/Inter.ttf`) | `invalidOption(name: "font", …"is a family name; pass a font file as fontFile")` |
| `fontSize: 3000` | `invalidOption`: "must be from 1 through 2000" |
| `.fit` with `lineHeight` other than 1 | `invalidOption`: "must be 1 with a fit layout" |
| invalid markup | `invalidInput`: "the text is not valid Pango markup" |
