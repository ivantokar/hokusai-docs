| Операція | Що робить |
| --- | --- |
| `extractChannel(_:)` | Один канал (`red`, `green`, `blue`, `alpha`, `luminance`) як сіре зображення. |
| `withAlpha(from:)` | Використовує інший конвеєр як альфа-канал. |
| `ensureAlpha(opacity:)` | Додає альфа-канал, якщо його немає. |
| `flatten(background:)` | Накладає на суцільний колір і прибирає альфа-канал. |
| `removeAlpha()` | Відкидає альфа-канал. |

:::note[Докладні посібники в розробці]
На цій сторінці перелічено, що надає Hokusai у задокументованому релізі. Посібники з кожної операції, з параметрами, значеннями за замовчуванням, візуальними результатами та взаємодіями, додаються; точний контракт API міститься в коментарях до вихідного коду бібліотеки.
:::
