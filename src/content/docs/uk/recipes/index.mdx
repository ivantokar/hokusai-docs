Кожен рецепт розв'язує одну реальну задачу від початку до кінця. У кожного є **вхідні дані** (фікстури для завантаження), **виконуваний Swift** (код виконує Hokusai, а зображення — це його вивід, перевірений у CI), **результати** та **варіації** з власними результатами. Для однорядкових прикладів дивіться [Швидкі приклади](/oss/hokusai/uk/examples).

| Рецепт | Що ви отримаєте |
| --- | --- |
| [Соціальна картка](/oss/hokusai/uk/recipes/social-card) | Попередній перегляд посилання 1200 × 630 із заголовком з будь-якого фото |
| [Мініатюри галереї](/oss/hokusai/uk/recipes/thumbnails) | Кілька розмірів з одного джерела, створених паралельно |
| [Водяний знак](/oss/hokusai/uk/recipes/watermark) | Підготовлений логотип, застосований до багатьох зображень, і ледь помітна плитка для проб |
| [Круглий аватар](/oss/hokusai/uk/recipes/avatar) | Квадратне обрізання з круглою маскою та плоский запасний варіант |
| [Контактний аркуш](/oss/hokusai/uk/recipes/contact-sheet) | Сітка плиток, зібраних на одному полотні |
| [PDF-звіт](/oss/hokusai/uk/recipes/pdf-report) | Векторний PDF зі справжнім текстом і зображеннями, підготовленими Hokusai |
| [Нормалізація завантаження](/oss/hokusai/uk/recipes/upload-normalisation) | Недовірене завантаження → обмежений, вертикальний WebP без метаданих |

Усі рецепти працюють на фікстурах із [`examples/fixtures`](https://github.com/ivantokar/hokusai-docs/tree/main/examples/fixtures): `scene.png` (пейзаж 1600 × 1000), `phone.jpg` (та сама сцена, збережена боком з орієнтацією EXIF), `emblem.png` (логотип 400 × 400 з прозорістю). Їх генерує код у репозиторії, і вони мають ліцензію MIT. Щоб відтворити всі результати: `cd examples && swift run DocsExamples run`.
