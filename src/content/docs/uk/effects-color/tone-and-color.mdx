## Довідник \{#reference}
| Операція | Параметри (значення за замовчуванням, межі) | Що робить |
| --- | --- | --- |
| `grayscale()` | немає | Прибирає колір, але **зберігає розкладку RGB(A)**; яскравість із перетворення sRGB у libvips. |
| `tint(_ color:)` | `Color` | Робить зображення сірим, потім відображає яскравість на колір: біле стає тоном, чорне лишається чорним. Власна непрозорість кольору ігнорується. |
| `normalize(lower:upper:)` | `1`, `99` | Відсікає найтемніші `lower` відсотків і найсвітліші `100 − upper`, потім розтягує решту на повний діапазон однією лінійною функцією для всіх смуг, тож відтінок зберігається. Пласке зображення повертається без змін. Лише 8- або 16-бітні. |
| `clahe(width:height:maxSlope:)` | `8`, `8`, `3`; `maxSlope` у `0…100` | Локальне посилення контрасту за світлотою (LAB); колір зберігається. `width`/`height` — розмір плитки, `maxSlope` обмежує приріст контрасту на плитку (`0` вимикає обмеження). 8- і 16-бітні; float-зображення викидають `unsupported`. |
| `gamma(_ value:)` | `2.2`; `0.1…10` | `out = in ^ (1 / value)` для кольорових смуг: понад 1 робить півтони світлішими. |
| `modulate(brightness:saturation:hue:)` | `1`, `1`, `0`; `0…100`, `0…100`, скінченні градуси | Працює в LCH: яскравість масштабує світлоту, насиченість — кольоровість, відтінок повертається. |
| `negate(alpha:)` | `false` | Інвертує кольори; альфа інвертується лише за `alpha: true`. |
| `threshold(_ level:grayscale:)` | `128`, `true`; `0…255` | Пікселі на рівні `level` і вище стають білими, решта — чорними. З `grayscale` результат — одноканальна маска; без нього кожна смуга порівнюється окремо. |
| `convert(to:)` | `.sRGB` або `.grayscale` | Перетворює на вихідний кольоровий простір. |

`normalize` і `clahe` розв'язують одну задачу по-різному: `normalize` робить одне глобальне розтягування, `clahe` пристосовується до кожної плитки. На плавних градієнтах мала плитка `clahe` може показати сітку сходинок, тож для фото неба беріть більші плитки й малий `maxSlope` (приклад вище використовує плитки 48 px і `maxSlope: 2`).

## grayscale() проти convert(to: .grayscale) \{#grayscale}
<Example id="effects.convert" results={[
  { file: 'grayscale-rgb.png', label: 'grayscale()', alt: 'Пейзаж у сірому, збережений із трьома кольоровими каналами.' },
  { file: 'grayscale-1ch.png', label: 'convert(to: .grayscale)', alt: 'Те саме сіре зображення, збережене з одним каналом.' },

Обидва виглядають однаково; вони відрізняються розкладкою. `grayscale()` зберігає три канали, тож подальші кольорові операції (`tint`, `recombine`) і RGB-кодувальники поводяться як зі звичайним кольоровим зображенням. `convert(to: .grayscale)` дає **один** канал (плюс альфа, якщо є), що менше на диску (тут 17 КБ проти 23 КБ) і саме потрібне масками та 8-бітним сірим виводам.

## Помилки \{#errors}
<Example id="effects.limits" />

| Виклик | Результат |
| --- | --- |
| `gamma(20)` | `invalidOption`: «must be a finite value from 0.1 to 10» |
| `threshold(300)` | `invalidOption`: «must be in 0...255» |
| `modulate` з `brightness` чи `saturation` поза `0…100` або нескінченним `hue` | `invalidOption` |
| `clahe` з `maxSlope` поза `0…100` | `invalidOption` |
| `clahe` на float-зображенні | `HokusaiError.unsupported` |
| `normalize` на зображенні не 8- чи 16-бітному | не підтримується (операція вимагає 8- або 16-бітного зображення) |
