Серверу, що отримує зображення потоком частин, не обов'язково тримати все тіло, щоб його декодувати. `Hokusai(spooling:options:memoryLimit:spoolDirectory:)` споживає `AsyncSequence` з `Data` (форма з `ByteBuffer` є в `HokusaiNIO`) і повертає конвеєр.

## Як це працює \{#how}
- Завантаження лишається в пам'яті, поки вкладається в `memoryLimit` (типово 1 МіБ; `0` — завжди через файл). Далі воно переходить у **приватний тимчасовий файл**, тож закодоване завантаження ніколи не займає більше ніж `memoryLimit` плюс одна частина пам'яті, яким би великим воно не було. libvips читає зображення з файлу з довільним доступом.
- Це обмежує лише закодоване завантаження. Пам'ять, яку libvips використовує для декодування й перетворення зображення, — окрема справа, її обмежують `InputLimits.maxPixels` і `InputOptions.access`.
- **`InputLimits.maxBytes` застосовується під час читання тіла**: частина, що його перетинає, викидає `resource` (`encodedBytes`), а решта тіла вже не запитується. Вище 19 частин не більше ніж по 16 КіБ з `maxBytes: 50_000` зупинилися на `actual: 65536`, тобто на частині, що перетнула ліміт.
- Конвеєр **володіє файлом**. Його вилучають, коли вивільняється остання копія конвеєра та будь-яке виконання на ньому; невдале чи скасоване читання вилучає його одразу. Процес, який завершили примусово, залишає свій файл: файли називаються `hokusai-upload-…`, читаються лише власником, у `spoolDirectory` (типово системний тимчасовий каталог, який має існувати), тож сервер може підчищати цей каталог під час запуску.
- Записи у файл виконуються у фонових чергах, поки завдання, що викликає, призупинене, тож повільний диск не може затримати непов'язану асинхронну роботу.

## Помилки \{#errors}
| Ситуація | Результат |
| --- | --- |
| Порожнє завантаження | `invalidInput` |
| Понад `maxBytes` | `resource` (`encodedBytes`) |
| Хибний параметр (напр., від'ємний `memoryLimit`) | `invalidOption` |
| Файл не вдається створити чи записати (немає каталогу, права, повний диск) | `io` |
| Що б не викинула послідовність | перевикидається без змін |

Hokusai Vapor і Hokusai Hummingbird викликають це за вас ([Інтеграції](/oss/hokusai/uk/integrations/)).
