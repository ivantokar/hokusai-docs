Коли пікселі вже є в пам'яті (кадр камери, відтворена діаграма, тестові дані), `Hokusai(raw:width:height:format:rowStride:premultiplied:limits:)` будує з них конвеєр, а `raw(_:premultiplied:background:)` повертає пікселі як `RawImage`. Необроблені й закодовані конвеєри мають спільні всі перетворення.

## RawPixelFormat \{#formats}
Вибірки чергуються (`RGBRGB…`), беззнакові, без заповнення між пікселями. Кольорові канали йдуть першими, а альфа, якщо є, останньою. 16-бітні вибірки використовують порядок байтів машини, тобто little-endian на кожній підтримуваній платформі. Колір — sRGB; сіре — та сама крива передачі з одним каналом. **До необроблених пікселів жоден колірний профіль не застосовується.**

| Формат | Канали | Байтів на піксель |
| --- | --- | --- |
| `gray8` | сірий | 1 |
| `grayAlpha8` | сірий, альфа | 2 |
| `rgb8` | червоний, зелений, синій | 3 |
| `rgba8` | червоний, зелений, синій, альфа | 4 |
| `gray16` | сірий | 2 |
| `grayAlpha16` | сірий, альфа | 4 |
| `rgb16` | червоний, зелений, синій | 6 |
| `rgba16` | червоний, зелений, синій, альфа | 8 |

## Вхід \{#input}
Параметри: `data`, `width` і `height` (`1…2 147 483 647`), `format`, необов'язковий `rowStride` (байти між початками рядків; `nil` означає щільно упаковано, `width × bytesPerPixel`), `premultiplied` (чи кольорові канали вже було помножено на альфу; їх ділять на завантаженні, тож кожна наступна операція бачить пряму альфу; ігнорується для форматів без альфи) і `limits`. Розміри, крок і кількість байтів перевіряються з виявленням переповнення **до будь-якого нативного виклику**, тож брехливий заголовок не може «обернутися».

## Вивід \{#output}
`raw(_ format:premultiplied:background:)` (типово `.rgba8`, `false`, `.white`) повертає `RawImage`, що вказує все потрібне для читання: `data`, `width`, `height`, `format`, `rowStride`, `premultiplied`, `byteCount`. Рядки йдуть згори донизу, а пікселі — зліва направо. Власний вивід Hokusai щільно упакований (`rowStride == width × bytesPerPixel`, а приклад вивів крок 192 і 12 288 байтів для кадру `rgb8` 64 × 64). Передайте `RawImage` назад у `Hokusai(raw:)` без змін, щоб пройти цикл. `background` заповнює прозорість, коли формат не має альфи.

`raw` **не має кодувальника**: виклик на конвеєрі з обраним кодувальником викидає `invalidOption` («an encoder is selected; raw output has no encoder, so use data() for an encoded image»).

## Помилки \{#errors}
| Ситуація | Результат |
| --- | --- |
| Кількість байтів не відповідає геометрії | `invalidInput`: «raw data is 10 bytes; a 4×2 rgba8 image with a row stride of 16 needs 32» |
| Недопустимий чи завеликий розмір, замалий крок або рядок, що переповнюється | `invalidOption`, викидається ініціалізатором |
| Перевищено ліміти | `resource` |
