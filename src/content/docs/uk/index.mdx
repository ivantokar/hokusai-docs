## Чому Hokusai? \{#why-hokusai}

Hokusai 1.0 — це основний пакет Swift для високопродуктивної серверної обробки зображень. Він приймає вхідні дані `Data` або файловий `URL`, надає типізований вивід у JPEG, PNG, WebP, AVIF і PDF та тримає блокувальне нативне виконання поза кооперативним виконавцем Swift.

- **Висока продуктивність:** libvips ефективно обробляє зображення без дочірніх процесів.
- **Безпечна конкурентність:** незмінні конвеєри можна розгалужувати між завданнями до виконання виводу.
- **Типізований вивід:** обирайте JPEG, PNG, WebP, AVIF або PDF на базі Cairo через API Swift.
- **Інтеграція із сервером:** декодуйте завантаження й повертайте відповіді правильного типу через Hokusai Vapor.

## Короткий приклад \{#quick-example}

```swift
let thumbnail = try await Hokusai(url: URL(fileURLWithPath: "photo.jpg"))
    .autoOrient()
    .resize(width: 400)
    .jpeg(quality: 85)
    .write(to: URL(fileURLWithPath: "thumbnail.jpg"))
```
