## Чому Hokusai? \{#why-hokusai}

Hokusai — це пакет Swift для високопродуктивної серверної обробки зображень. Він приймає вхідні дані `Data`, файловий `URL`, необроблені пікселі та завантаження, що надходять частинами, надає типізований вивід у JPEG, PNG, WebP, AVIF, HEIF, TIFF, GIF і PDF та тримає блокувальне нативне виконання поза кооперативним виконавцем Swift. Ці сторінки документують Hokusai {versions.hokusai}, Hokusai Vapor {versions.vapor} і Hokusai Hummingbird {versions.hummingbird}.

- **Висока продуктивність:** libvips ефективно обробляє зображення без дочірніх процесів.
- **Безпечна конкурентність:** незмінні конвеєри можна розгалужувати між завданнями до виконання виводу.
- **Типізований вивід:** обирайте JPEG, PNG, WebP, AVIF, HEIF, TIFF, GIF або PDF на базі Cairo через API Swift.
- **Інтеграція із сервером:** декодуйте завантаження й повертайте потокові відповіді правильного типу через Hokusai Vapor або Hokusai Hummingbird.

## Короткий приклад \{#quick-example}

```swift
let thumbnail = try await Hokusai(url: URL(fileURLWithPath: "photo.jpg"))
    .autoOrient()
    .resize(width: 400)
    .jpeg(quality: 85)
    .write(to: URL(fileURLWithPath: "thumbnail.jpg"))
```
