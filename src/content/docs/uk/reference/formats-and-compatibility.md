## Входи та виходи {#inputs-and-outputs}

Створіть конвеєр із `Data` зображення або локального файлового `URL`:

```swift
let fromData = try Hokusai(data: uploadData)
let fromFile = try Hokusai(url: URL(fileURLWithPath: "photo.jpg"))
```

Використовуйте типізований кодувальник, щоб отримати один із форматів виводу Hokusai:

| Формат | Кодувальник конвеєра | Типові параметри |
| --- | --- | --- |
| JPEG | `.jpeg()` | якість, прогресивний, субдискретизація кольору |
| PNG | `.png()` | рівень стиснення, черезрядковий, палітра |
| WebP | `.webp()` | якість, зусилля, без втрат, пресет |
| AVIF | `.avif()` | якість, зусилля, без втрат, бітова глибина |
| HEIF | `.heif()` | стиснення (`hevc`, `av1`), якість, без втрат |
| TIFF | `.tiff()` | стиснення, якість, предиктор, мозаїка |
| GIF | `.gif()` | бітова глибина, дизеринг, зусилля, черезрядковий |
| PDF | `.pdf()` | розмір сторінки, поля, прив'язка, тло, максимальний ефективний DPI, метадані |

`write(to:)` може визначати формат виводу за розширенням файлу, де це підтримується. Обирайте типізований кодувальник явно, коли потрібні параметри, специфічні для кодувальника.

## Підтримка платформ {#platform-support}

Hokusai підтримує macOS 13+ та Linux зі встановленими Swift 6.0+, libvips 8.16+, Cairo 1.16+ з підтримкою PDF і `pkg-config`. Які формати можна читати чи записувати понад базовий рівень, залежить від того, як зібрано libvips: викличте `Hokusai.capabilities()` або виконайте `hokusai info`, щоб побачити, що підтримує ваше встановлення.

## Сумісність {#compatibility}

Публічний API використовує незмінні конвеєри й асинхронне завершальне виконання. Відповідність API та зміни поведінки між релізами дивіться в розділі [Міграція](/oss/hokusai/uk/guide/migration).
