## Входи та виходи {#inputs-and-outputs}

Створіть конвеєр із `Data` зображення або локального файлового `URL`:

```swift
let fromData = try Hokusai(data: uploadData)
let fromFile = try Hokusai(url: URL(fileURLWithPath: "photo.jpg"))
```

Використовуйте типізований кодувальник, щоб отримати один із форматів виводу Hokusai v1:

| Формат | Кодувальник конвеєра | Типові параметри |
| --- | --- | --- |
| JPEG | `.jpeg()` | якість, прогресивний |
| PNG | `.png()` | рівень стиснення, прогресивний |
| WebP | `.webp()` | якість, зусилля, без втрат |
| AVIF | `.avif()` | якість |
| PDF | `.pdf()` | розмір сторінки, DPI |

`write(to:)` може визначати формат виводу за розширенням файлу, де це підтримується. Обирайте типізований кодувальник явно, коли потрібні параметри, специфічні для кодувальника.

## Підтримка платформ {#platform-support}

Hokusai підтримує macOS 13+ та Ubuntu/Debian Linux зі встановленими Swift 6.0+, libvips 8.9+, Cairo і `pkg-config`. Для PDF-виводу в середовищі libvips потрібна підтримка Cairo.

## Сумісність із версією 1.0 {#version-10-compatibility}

Версія 1.0 є релізом із несумісними змінами. Публічний API тепер використовує незмінні конвеєри й асинхронне завершальне виконання. Відповідність API дивіться в розділі [Міграція з 0.x](/oss/hokusai/uk/guide/migration).

Продукт `HokusaiLegacy` призначений для свідомого тимчасового переходу з адаптерів 0.x. Його не слід використовувати в новому коді застосунків.
