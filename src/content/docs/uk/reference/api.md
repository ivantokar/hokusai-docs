API Hokusai побудований навколо незмінних конвеєрів зображень: завантажте зображення, складіть перетворення, а потім асинхронно виконайте закодований результат.

## Основна бібліотека {#core-library}

- [Конвеєри та конкурентність](/oss/hokusai/uk/guide/pipelines) — завантаження даних зображення, розгалуження рецептів, метадані та життєвий цикл.
- [Перетворення](/oss/hokusai/uk/guide/transformations) — зміна розміру, обрізання, обертання, розмиття, різкість, альфа-канал і кольорові операції.
- [Текст, композиція та PDF](/oss/hokusai/uk/guide/composition-and-pdf) — шари, локальні шрифти й односторінкові PDF на базі Cairo.
- [Формати та сумісність](/oss/hokusai/uk/reference/formats-and-compatibility) — типізовані параметри кодувальників для кожного формату виводу та підтримка платформ.

## Vapor {#vapor}

Hokusai Vapor додає до Vapor 4 декодування запитів і потокові відповіді із зображеннями та PDF. Hokusai Hummingbird робить те саме для Hummingbird 2; дивіться [Інтеграції](/oss/hokusai/uk/integrations/).

- [Огляд інтеграції](/oss/hokusai/uk/vapor/overview)
- [Завантаження та відповіді](/oss/hokusai/uk/vapor/uploads-and-responses)

## Командний рядок {#command-line}

Виконуваний файл `hokusai` підтримує перевірку середовища виконання, перетворення зображень, відтворення тексту, мініатюри та бенчмарки конвеєрів.

[Довідник CLI](/oss/hokusai/uk/reference/cli)

## Індекс операцій {#operation-index}

Усі операції, згруповані за призначенням: [Індекс операцій](/oss/hokusai/uk/reference/operations). Точний контракт кожного символу (параметри, значення за замовчуванням, помилки) міститься в коментарях до вихідного коду бібліотеки; цей сайт навчає, як операції поводяться й поєднуються.
