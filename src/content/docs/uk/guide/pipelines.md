Значення Hokusai представляють рецепт, а не обчислені пікселі зображення. Кожне перетворення створює нове незмінне значення, тож вихідний конвеєр можна безпечно використовувати повторно.

```swift
let source = try Hokusai(url: URL(fileURLWithPath: "photo.jpg"))
let card = source.resize(width: 1200, height: 630, fit: .cover)
let thumbnail = source.resize(width: 400)

async let cardData = card.webp(quality: 82).data()
async let thumbnailData = thumbnail.jpeg(quality: 85).data()
let outputs = try await (cardData, thumbnailData)
```

## Завершальні операції виконання {#evaluation-terminals}

Конвеєри виконуються лише завершальними операціями виводу:

- `data()` повертає закодовані байти та відомості про вивід.
- `write(to:)` кодує й записує у файловий `URL`.

Ці операції виконують блокувальну роботу libvips поза кооперативним виконавцем Swift. Будуйте перетворення як звичайно; використовуйте `await` лише тоді, коли роботу потрібно виконати.

## Життєвий цикл середовища виконання {#runtime-lifecycle}

Завантаження зображення ліниво ініціалізує середовище виконання. Виклик `Hokusai.initialize()` необов'язковий, але корисний під час запуску застосунку, щоб виявити проблеми з нативними залежностями до обслуговування трафіку.

У Hokusai немає публічного виклику завершення роботи: не додавайте хук завершення до життєвого циклу сервера.

## Метадані {#metadata}

Перевіряйте метадані джерела, перш ніж ухвалювати рішення про компонування. `metadata()` є асинхронним і описує джерело таким, яким його відкрито, а не перетворений конвеєр:

```swift
let image = try Hokusai(data: upload)
let metadata = try await image.metadata()
print("\(metadata.width) × \(metadata.height)")
```

Те, що зберігає вивід, — це `MetadataPolicy`, яку обирають через `metadataPolicy(_:)`. За замовчуванням EXIF, XMP, IPTC і коментарі вилучаються, а профіль ICC, орієнтація та щільність зберігаються; використовуйте `.preserveAll` лише тоді, коли споживач нижче за потоком потребує вбудованих метаданих.
