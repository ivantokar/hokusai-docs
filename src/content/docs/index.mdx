## Why Hokusai?

Hokusai is a Swift package for high-performance server-side image processing. It accepts `Data`, file `URL`, raw pixel and streamed upload inputs, provides typed JPEG, PNG, WebP, AVIF, HEIF, TIFF, GIF, and PDF outputs, and keeps blocking native evaluation away from Swift's cooperative executor. These pages document Hokusai {versions.hokusai}, Hokusai Vapor {versions.vapor} and Hokusai Hummingbird {versions.hummingbird}.

- **High performance:** libvips processes images efficiently without child processes.
- **Safe concurrency:** immutable pipelines can be branched across tasks before output evaluation.
- **Typed output:** choose JPEG, PNG, WebP, AVIF, HEIF, TIFF, GIF, or Cairo-backed PDF with Swift APIs.
- **Server integration:** decode uploads and return correctly typed, streamed responses through Hokusai Vapor or Hokusai Hummingbird.

## Quick example

```swift
let thumbnail = try await Hokusai(url: URL(fileURLWithPath: "photo.jpg"))
    .autoOrient()
    .resize(width: 400)
    .jpeg(quality: 85)
    .write(to: URL(fileURLWithPath: "thumbnail.jpg"))
```
