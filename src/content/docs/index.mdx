## Why Hokusai?

Hokusai 1.0 is the core Swift package for high-performance server-side image processing. It accepts `Data` or file `URL` inputs, provides typed JPEG, PNG, WebP, AVIF, and PDF outputs, and keeps blocking native evaluation away from Swift's cooperative executor.

- **High performance:** libvips processes images efficiently without child processes.
- **Safe concurrency:** immutable pipelines can be branched across tasks before output evaluation.
- **Typed output:** choose JPEG, PNG, WebP, AVIF, or Cairo-backed PDF with Swift APIs.
- **Server integration:** decode uploads and return correctly typed responses through Hokusai Vapor.

## Quick example

```swift
let thumbnail = try await Hokusai(url: URL(fileURLWithPath: "photo.jpg"))
    .autoOrient()
    .resize(width: 400)
    .jpeg(quality: 85)
    .write(to: URL(fileURLWithPath: "thumbnail.jpg"))
```
